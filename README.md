Repositório central para o desenvolvimento dos Trabalhos Práticos da disciplina de Fundamentos de Inteligência Artificial.

## Sobre a Disciplina
Este ambiente concentra as implementações e documentações exigidas ao longo do curso. O objetivo principal é a aplicação prática de conceitos teóricos de IA, englobando desde a modelagem de espaços de estados e algoritmos de busca (cega e informada) até representação de conhecimento e tomada de decisão.

## Estrutura do Repositório
O projeto está organizado de forma modular para acomodar as diferentes entregas ao longo do semestre, separando rigorosamente a documentação do código-fonte.

* `tp1/`: Diretório dedicado ao Trabalho Prático 1.
  * `docs/`: Relatórios técnicos, arquivos LaTeX e diagramas de modelagem.
  * `src/`: Código-fonte dos agentes, função sucessora e algoritmos de busca.
* `pyproject.toml`: Configuração global do projeto e registro de dependências.

## Configuração do Ambiente
O gerenciamento de pacotes e do ambiente virtual Python é feito através do [uv](https://github.com/astral-sh/uv). 

Para inicializar o ambiente e instalar dependências de desenvolvimento (como ferramentas de linting e testes):
```bash
uv sync
```
